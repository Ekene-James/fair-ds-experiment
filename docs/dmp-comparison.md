# T4.5 DMP Comparison

## Initial DMP

The initial DMP described the planned datasets, expected storage, intended metadata, and planned FAIR principles for the project.

## Final DMP

The final DMP includes the actual repository structure, created metadata files, generated outputs, licences, and deposit information.

## Main differences

| Area | Initial DMP | Final DMP |
|---|---|---|
| Data | Planned football player datasets | Final reused input datasets and generated outputs |
| Metadata | Planned FAIR metadata | CodeMeta, RO-Crate, FAIR4ML, Croissant, Model Card |
| Licences | Not fully fixed | MIT for code, CC BY 4.0 for outputs, CC0 for metadata |
| Deposits | Planned deposits | Model DOI and generated-data deposit information |
| Reproducibility | Planned workflow | Repository contains code, metadata, README, and outputs |

## Conclusion

The final DMP is more complete because it reflects the real project implementation, final metadata standards, licences, and repository outputs.
