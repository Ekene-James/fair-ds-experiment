# T4.5 DMP Comparison

## Overview

This document compares the initial Data Management Plan (DMP) with the final DMP produced during the FAIR Data Science project.

---

# Initial DMP

The initial DMP focused on:

- Planned football player datasets
- Intended machine learning workflow
- Expected FAIR metadata usage
- Planned repository structure
- Proposed storage and preservation strategy

At the beginning of the project, several metadata standards and repository integrations were still incomplete.

---

# Final DMP

The final DMP includes:

- Completed FAIR metadata files
- GitHub repository integration
- DBRepo integration
- Generated prediction outputs
- Trained machine learning models
- Zenodo and TUWRD DOI deposits
- Reproducibility documentation
- Final licences and preservation details

The final DMP reflects the actual implementation of the project.

---

# Main Differences

| Area | Initial DMP | Final DMP |
|---|---|---|
| Metadata | Planned FAIR metadata | FAIR4ML, RO-Crate, CodeMeta, Croissant, Model Card completed |
| Repository | Planned structure | Final GitHub repository implemented |
| Data storage | Planned DBRepo use | DBRepo integration completed |
| Outputs | Planned prediction outputs | Predictions and evaluation metrics deposited |
| Licences | Not finalized | MIT, CC BY 4.0, CC0 finalized |
| Preservation | Planned preservation | DOI deposits and long-term storage completed |
| Documentation | Basic planning | README, tests, metadata, and FAIR documentation completed |

---

# Conclusion

The final DMP is significantly more complete than the initial version because it includes implemented FAIR metadata standards, repository integrations, generated outputs, persistent identifiers (DOIs), licences, and reproducibility information.

The project now satisfies the FAIR Data Science course requirements more effectively through documented workflows, metadata standards, and open repository deposits.
